# E2E Тесты

E2E тесты для Electron Timer приложения, написанные с использованием Playwright.

## Установка

Перед запуском тестов необходимо установить зависимости:

```bash
npm install
```

Также нужно установить браузеры для Playwright:

```bash
npx playwright install
```

## Запуск тестов

### Все тесты

```bash
npm run test:e2e
```

### С UI режимом

```bash
npm run test:e2e:ui
```

### В headed режиме (с видимым окном Electron)

```bash
npm run test:e2e:headed
```

## Структура тестов

Тесты находятся в файле `timer.spec.ts` и покрывают следующие сценарии:

- Начальное состояние окна, статус и доступность элементов управления
- Запуск, остановка, пауза и возобновление таймера
- Корректировка времени кнопками и быстрыми ссылками, включая ограничения во время работы
- Ввод длительности в разных форматах и проверка больших значений
- Сворачивание в трей, повторный показ окна и сохранение состояния интерфейса
- Восстановление настроек видимости после перезапуска
- Сохранение и восстановление настроек уведомлений, звука и countdown window через окно Settings
- Однократное уведомление о завершении таймера, пропущенном во время закрытия приложения
- Восстановление приостановленного таймера без ложного уведомления
- Защита файла настроек запущенного экземпляра от второго экземпляра приложения

## Примечания

Тесты запускают Electron приложение напрямую из тестов. Основной набор получает
свежий экземпляр и файл настроек перед каждым тестом. Конфигурация Playwright не
задаёт `webServer`; renderer загружает локальный HTML-файл (`file://` протокол).

Для работы тестов необходимо, чтобы приложение было собрано (`npm run build`).
